Overview

A small cache of normalized path expressions. It is guarded by a mutex, so threads can share it, and it holds at most max_size entries: when it is full the least recently used entry is dropped, so a long-running process that applies many distinct dynamic paths does not grow without limit.

def initialize(max_size = DEFAULT_MAX_SIZE)
  raise ArgumentError, "max_size must be a positive Integer, got #{max_size.inspect}" unless valid_size?(max_size)

  @max_size = max_size
  @data = {}
  @mutex = Mutex.new
end

def get_or_set(key)
  key = key.to_s
  hit, value = @mutex.synchronize { touch(key) ? [true, @data[key]] : [false, nil] }
  return value if hit

  @mutex.synchronize { store(key, yield(key)) }
end
