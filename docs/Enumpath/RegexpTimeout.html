Overview

Bounds how long a regular expression in a filter expression may run. A pattern with a backreference, such as /^(a*)*\1$/, can take exponential time to match a short string, so a hostile or careless path could hang the process.

The limit uses the timeout of Regexp.new, which needs Ruby 3.2 or later. Older Rubies have no protection and ignore the limit. Once one match runs out of time, every later regular expression match in the same apply call is skipped and does not match, so the total delay is bounded by one limit, not one limit per member of the data.

def limit(regexp)
  state = Thread.current[THREAD_KEY]
  raise ERROR, 'an earlier regular expression ran out of time' if state&.expired

  seconds = state ? state.seconds : DEFAULT
  return regexp unless SUPPORTED && seconds

  Regexp.new(regexp.source, regexp.options, timeout: seconds)
end
