Overview

A utility for resolving a string as a property (a public method that expects no arguments) of an object.

Which properties resolve is decided by a property resolver policy, set with the :property_resolver option of Enumpath.apply:

  • :safe (the default): read-only access only. See Property.safe?.
  • :readers: :safe, plus public methods written in Ruby (including those of installed gems) and ActiveModel-style attributes. See Property.reader?. This runs application and gem code and is not read-only.
  • :none: never call methods. Indexes, keys and Struct or Data members still resolve through Simple.
  • :all: call any public method that expects no arguments. This was the behavior of version 0.1 and lets a path run mutating or destructive methods such as clear, pop or destroy. Only use it with trusted paths.
  • a callable (anything that responds to call, such as a lambda): called as callable.call(object, name) with the property name as a String; the method is called only when it returns a truthy value. The callable has full control: none of the checks of the other policies are applied. It can call Property.safe? or Property.reader? to build on them.

The policy for the current Enumpath.apply call is kept in a fiber-local variable (Thread.current), so it reaches every operator without being passed through each one, and calls running in other threads or fibers do not see it. Outside of Enumpath.apply, and in a chained Enumpath::Results#apply that does not pass the option again, the default (:safe) applies.

.reader?(object, name) ⇒ true, false

Whether the :readers policy resolves a property of an object. Core objects (see CORE_CLASSES) are treated exactly like safe?. For any other object, either

  • the name is a plain identifier (see IDENTIFIER), not in READERS_DENYLIST, and the object publicly responds to it with a method that expects no arguments and is written in Ruby outside of Ruby itself (see ObjectInspector.application_method?), so computed readers like full_name work; or
  • the object has an ActiveModel-style attributes method (no arguments, written in Ruby outside of Ruby itself) that returns a Hash with the name as a String key, so attributes like email work even before their reader methods are defined; or
  • safe? allows it.

In short, :readers runs any public method that expects no arguments and is written in Ruby, except Ruby's built-in methods, methods in the Ruby standard library directory, and READERS_DENYLIST. Methods implemented in C (core classes, StringIO, C-extension gems) are never called; objects of C-extension classes need a callable policy or :all. Methods from installed gems are called, including default and bundled gems such as Logger and CSV, and ActiveModel or ActiveRecord: for example Logger#close would run.

So :readers is not read-only. Use it for data you trust or objects you built. For untrusted paths use :safe, or a callable that builds on safe? with a per-class allowlist.

.safe?(object, name) ⇒ true, false

Whether the :safe policy resolves a property of an object. All of these must hold:

  • the name is a plain identifier (see IDENTIFIER);
  • the object publicly responds to it and the method has no required arguments;
  • and either
    • the name is in SAFE_METHODS, the object is one of SAFE_RECEIVERS, and the method is Ruby's own (owned by one of CORE_OWNERS, not overridden), in which case the method is called; or
    • the object is not one of CORE_CLASSES and has an instance variable of the same name (@name for name), as an attr_reader on a plain Ruby object does. In that case the instance variable is read directly and the method itself is never called, so a method that merely shares its name with an instance variable cannot run.

Struct and Data members are not handled here: they resolve as members through Simple.

A callable policy can build on this check to allow more methods while keeping the safe ones:

Examples:

Keep the safe defaults and allow specific methods per class

ALLOWED = { 'Invoice' => %w[total due_on], 'Customer' => %w[name email] }.freeze
policy = lambda do |object, name|
  Enumpath::Resolver::Property.safe?(object, name) || ALLOWED.fetch(object.class.name, []).include?(name)
end
Enumpath.apply('invoices.*.total', account, property_resolver: policy)
